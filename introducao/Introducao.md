# Algoritmo

## O que é algoritmo?

- Algoritmo é um processo sistemático para resolução de  um problema. Baseado na natureza dos computadores, algoritmos são importantes para solucionar problemas computacionais, existem dois aspectos básicos no estudo de algoritmos: correção e análise.

- Um algoritmo a partir de uma entrada computa uma saída, que é o resultado do problema. Durante o processo de computação o algoritmo manipula os dados de entrada ou gerados a partir da entrada.
- Dados de entrada dispostos de forma homogênea constituem um tipo abstrato de dados. As estruturas de dados não podem ser disvinculadas dos aspectos algorítmicos.

- A escolha correta da estrutura adequada a cada caso depende diretamente do conhecimento de algoritmos para manipular a estrutura de maneira eficiente.

## Recursividade

- É aquele que contém uma ou mais chamadas a si mesmo, procedimento recursivo e cada chamada é denominada chamada recursiva.

- Um processo não recursivo é aquele em que todas as chamadas são externas.

- Para todo procedimento recursivo há um processo não recursivo que executa a mesma computação.

- Vantagens: São no geral mais concisos, muitas vezes é aparente a relação entre um algoritmo recursivo e uma prova por indução matemática.

- Um algoritmo não recursivo equivalente pode ser mais eficiente.
