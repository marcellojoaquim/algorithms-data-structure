# Linear lists
<p> Among non-primitive data structures, linear lists are the simplest to manipulate. A linear list groups information that is somehow related to each other. The most frequent operations are: Searching, inserting and removing elements, such operations can be considered basic and for this reason the algorithms that implement them must be efficient. Linear lists can also be classified according to the type of storage and their relative position in memory, we have sequential allocation in memory and chained allocation.</p>
